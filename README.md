## 📑 Project Overview
This repository contains a full simulation of the SAAQ driver's license exam. It covers:
* **Road Signs** (Signaling)
* **Highway Safety Code** (Laws)
* **Driving Techniques** (Specialized maneuvers)

## 🚀 Features
* 🔄 **Randomized Quizzes:** Never see the same test twice.
* 🛑 **Sign Library:** Visual breakdown of every Quebec road sign.
* 📈 **Analytics:** Track your score and see if you are ready for the real exam.
